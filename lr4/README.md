# Luma TCP Chat

**Luma TCP Chat** — десктопное приложение для прямого обмена сообщениями и файлами между двумя компьютерами в локальной сети. Не требует интернета и центрального сервера.

## Возможности

- ✅ Создание TCP-сервера (режим хоста) и подключение к другому ПК
- ✅ Автоматическое обнаружение активных хостов в локальной сети (UDP broadcast)
- ✅ Отправка текстовых сообщений (UTF-8, поддержка русского языка)
- ✅ Отправка файлов до 5 МБ (изображения, документы)
- ✅ Уведомления о новых сообщениях (всплывающий popup + звук)
- ✅ Сохранение истории переписки (последние 200 сообщений)
- ✅ Стильный современный интерфейс (стеклянные панели, градиенты)

## Инструкция по использованию

### Для создания чата (хост)
1. Запустите приложение.
2. Введите своё имя в поле **ПРОФИЛЬ**.
3. Убедитесь, что порт (по умолчанию 5000) не занят.
4. Нажмите **Создать**.
5. Сообщите другому пользователю свой IP-адрес (отображается в боковой панели) или дождитесь автоматического обнаружения.

### Для подключения к чату (клиент)
1. Запустите приложение.
2. Нажмите **Обновить** — приложение найдёт все активные хосты в сети.
3. Выберите нужный контакт из списка.
4. Нажмите **Войти**.
5. После установки соединения можно отправлять сообщения и файлы.

### Отправка файлов
- Нажмите кнопку **+** в поле ввода сообщения.
- Выберите файл (до 5 МБ).
- Дождитесь завершения передачи (индикатор прогресса).
- Полученные файлы сохраняются в папке `Мои документы\LumaChatFiles`.
